This site started as a place to practice building with React. At the time, that was part of the point: I wanted to explore components, interactions, and the tools I was using in my work.

The site eventually became more complicated than the job it needed to do. A personal site doesn’t have to behave like an application. It can simply introduce someone, point toward their work, and offer a quiet place to write.

So I’m starting again with a smaller set of ideas:

- Make the important things easy to find.
- Send as little JavaScript as possible.
- Keep writing in portable Markdown files.
- Add interactivity only when an idea genuinely benefits from it.

Astro gives me that foundation. Most of this site is generated as plain HTML and CSS, while still leaving room for richer experiments inside an article when I want them.

This first post is also a small promise to use the site differently. Instead of treating it as a résumé that gets refreshed every few years, I want it to become a living collection of notes about engineering, products, and whatever else has my attention.
